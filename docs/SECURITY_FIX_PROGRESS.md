## Change log

- 2026-07-15: Started production remediation in risk order.
- 2026-07-15: Removed the startup database sanitizer from the deployable source tree. Disabled admin seeding by default and in SAM, rejected blank/known default credentials, and redacted the password from logs. Backend compile passed.
- 2026-07-15: Blocked ADMIN self-registration; enforced banned-user checks for login, refresh and access tokens; revoked refresh tokens on bans/role changes; blocked role changes with active obligations; blocked self-application. Seven targeted auth tests passed.
- 2026-07-15: Disabled deposit/withdraw cash simulation by default and in SAM; made missing escrow report as unfunded; added pessimistic row locks for users, tasks, escrows and application acceptance; added deadline recheck during acceptance. Eight targeted tests passed.
- 2026-07-15: Added task/submission/session ownership checks to AI flows; removed duplicate first chat message and sensitive email/wallet profile snapshots; restricted file extraction to approved HTTPS storage hosts, blocked private IPs/redirects, capped download/archive/pages/text, validated file signatures, and rejected unsupported image analysis; added AI/register/recovery rate limits with idle eviction. Six targeted AI/Bedrock tests passed.
- 2026-07-15: Enforced participant/admin visibility for submissions, revisions, evaluations, disputes, drafts and private files; made evaluation idempotent and task-scoped with validated weights/scores; allowed either participant to open a dispute but reserved resolution for admins; added private Supabase signed URLs and stored-object verification; restricted uploads by type, extension, signature and safe DOCX structure. Updated escrow-aware test fixtures. Forty targeted tests passed.
- 2026-07-15: Rebuilt milestone escrow as a coherent state machine: milestone totals cannot exceed the budget and must equal it before lock/funding; task escrow and milestone escrow are mutually exclusive; pessimistic locks prevent duplicate deductions/releases; all milestones must be funded before publish; submission marks open milestones submitted; rejection requests revision without refunding the hirer; admin-only refunds return principal plus fees; milestone release is idempotent and completes only after all payments release. Fourteen milestone/escrow/auth tests passed.
- 2026-07-15: Removed raw reset links and OTPs from logs; made recovery discovery non-enumerating; skipped undeliverable tokens when providers are disabled; added AWS SES security-mail support with scoped IAM; hashed SMS OTPs, locked rows and invalidated after five failed attempts; added Flyway V5 to invalidate legacy plaintext OTPs; made health verify the database; removed localhost production CORS and fixed Lambda origin reflection; tightened JWT/Bedrock production validation. Eighteen targeted tests passed and the SAM template validated.

ESLint completed with zero errors and both client/SSR production builds passed.
